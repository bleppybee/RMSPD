Advanced Tools ⚔🎲

Dice options

Create labels such as Attack roll, Damage roll, or any custom tag. Mark a reader line as a dice line to attach its selected label and roll mode.

Persistent dice characters

Tags and line assignments are stored in the project. Script markers look like [[dice: Attack roll | advantage]]; use [[dice: off]] to override a dice character for one line.
Initiative behaviour
When chapter ending is enabled, the remember option carries initiative through exactly one chapter before resetting. Turning off the Exit option defers an Exit marker until the next chapter.

Advanced tools and syntax
Insert symbol:
Use :: Scene Name :: to start a scene, or :: Chapter: Name :: to mark a chapter. Initiative markers can be :: ⚔ Enter Initiative :: and :: ⚔ Exit Initiative ::. Use -: (or null:) for narration. Use CW: for a content warning. Add [1] tags for translator notes. Optional image: [[img: images/example.png | caption]]. A line with only Image creates a paste slot. Dialogue lines can use character display names or shortcuts.
