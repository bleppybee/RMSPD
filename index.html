Dice Options 🎲

Set which characters regularly make rolls, create reusable roll types, and choose how initiative ends. You can still override any individual line in the Visual Novel Reader.

Character dice defaults

Enable a character when their dialogue should be treated as a roll by default. A line-specific choice in the reader takes priority.

Roll types

Create reusable labels such as Attack roll, Damage roll, or Strength check.

Show roll-type script syntax
Roll types and line assignments are stored in the project. Script markers look like [[dice: Attack roll | advantage]]; use [[dice: off]] to turn off a character default for one line.
Initiative behaviour
When chapter ending is enabled, the remember option carries initiative through exactly one chapter before resetting. Turning off the Exit option defers an Exit marker until the next chapter.
